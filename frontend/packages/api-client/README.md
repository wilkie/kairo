# @kairo/api-client

Typed daemon API client for the Kairo web client. Wraps the
OpenAPI-generated `paths` schema with `openapi-fetch` and a
small `KairoApiClient` facade.

## Layout

- `src/generated/schema.ts` — generated by `openapi-typescript`
  from the workspace-root `openapi/kairo-daemon.json`. **Do not
  edit by hand.** Re-generate with `pnpm generate:api`.
- `src/client.ts` — the `createKairoClient(baseUrl)` factory and
  the public `KairoApiClient` interface.
- `src/index.ts` — package entry point. Re-exports the types
  consumers will reach for.

## Regenerating the generated schema

The single source of truth is the daemon's utoipa annotations.
The pipeline is:

```text
utoipa annotations → kairo-daemon dump-openapi → openapi/kairo-daemon.json
                    (Rust drift test on the daemon side)
                                                                  │
                                                                  ▼
                                       openapi-typescript (this package)
                                                                  │
                                                                  ▼
                                                  src/generated/schema.ts
```

Run from the frontend root:

```sh
pnpm generate:api
```

The generated file is committed so consumers can typecheck without
running the generator. Slice 6 onward expects this file to be in
sync with the on-disk `openapi/kairo-daemon.json`.

## v1 surface

Slice 5 ships a thin `getVersion()` method so the shell page can
exercise the proxy end-to-end. Slice 6 fills in the remaining 11
endpoints (`getStatus`, `getActor`, `getObject`, `getStatement`,
`listBranches`, `getLatestBranch`, `getLatestVersionTag`,
`getTrust`, `listCapabilitiesFromGrantor`, `getBlob`, and
`verifyObject`).
